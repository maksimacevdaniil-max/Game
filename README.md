# Island Survival 3D

Мобильная 3D-игра о выживании на большом тропическом острове.

**Платформа:** Android-смартфоны.  
**Движок:** Godot 4.4+.  
**Рендер:** Mobile / GL Compatibility.  
**Ориентация:** альбомная.

## План разработки

### Этап 1 — карта острова
- Большой цельный остров с пляжами, лесом, холмами и горными вершинами.
- Процедурный рельеф и раскраска поверхности по высоте.
- Океан с анимированной поверхностью.
- Река, пещера, скалы, пальмы, тропические деревья, кусты и валуны.
- Атмосфера, солнце, небо и обзорная камера.
- Временная автоматическая камера нужна только для осмотра карты; это не игровое управление.

### Этап 2 — персонаж
- Полноценная 3D-модель человека.
- Скелет и анимации.
- Посадка персонажа в созданный мир.

### Этап 3 — мобильное управление
- Экранный джойстик.
- Сенсорный обзор камеры.
- Кнопки прыжка, бега и приседания.
- Камера от третьего лица и мобильная оптимизация.

**Важно:** игра разрабатывается для телефона. Управление с клавиатуры и мыши не входит в проект.

## Запуск проекта

1. Установить Godot 4.4 или новее.
2. Импортировать папку репозитория как Godot project.
3. Открыть сцену res://scenes/main.tscn и нажать Run.

На текущем этапе реализуется только карта острова. Персонаж и экранное управление будут добавлены отдельными следующими этапами.
